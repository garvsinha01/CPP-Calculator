
# C++ Calculator

A simple calculator program written in C++ that performs basic arithmetic operations.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Prevents division by zero
- User-friendly input

## Example

Input:
```
Enter first number: 15
Enter operator (+, -, *, /): *
Enter second number: 8
```

Output:
```
Result = 120
```
